# Orbit Web OS

A basic web-based operating system desktop built with plain HTML, CSS, and JavaScript.

## Run

Open `index.html` in a browser. No build step or dependencies are required.

## Included

- Desktop layout with launcher and dock
- Desktop pulse card with live greeting, date, open-window count, and quick actions
- Focus mode, randomized accent palettes, and a close-all workspace action
- Notes, Files, Terminal, About, Calculator, Paint, Clock, Orbit Dash, and Calendar apps
- Browser app with address bar, embedded websites, navigation, and reload controls
- Snake and Minesweeper games with keyboard, click, flag, score, and reset interactions
- Paint canvas with color, brush size, clear, and PNG export controls
- Draggable app windows
- Minimize, maximize, restore, and close controls for app windows
- Window focus and close behavior
- Live clock and light/dark theme toggle
